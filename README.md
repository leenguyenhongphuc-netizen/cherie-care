# CHÉRIE Care

Website care.cherie.io.vn: giặt khô, hấp, sửa đồ nữ theo từng món ở Đà Nẵng.

- `index.html`: trang khách (bảng giá Chuẩn / Signature, váy cưới theo dáng, cam kết đền bù, đặt lịch, tra cứu đơn, doanh nghiệp, hỏi đáp).
- `quanly/`: app quản lý (nhận đồ có 4 ảnh tình trạng, xưởng, trả đồ, tổng quan, cài đặt).
- `server/Code.gs`: máy chủ Google Apps Script, dán vào Sheet "CHÉRIE Care · Quản lý".
- `config.js`: link triển khai Apps Script (đuôi /exec).
- `CNAME`: tên miền care.cherie.io.vn.

Dữ liệu và đăng nhập tách riêng với cherie.io.vn và Office.
